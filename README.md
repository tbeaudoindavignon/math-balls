## Balls

| Ball | Formula | Growth Pattern | Quirk |
|------|---------|----------------|-------------|
| Fibonacci | F(n) = F(n-1) + F(n-2) | 1, 2, 3, 5, 8, 13... | Gravity = 0.2 |
| Factorial | n! | 1, 2, 6, 24, 120... | Gravity = 0.2 |
| Power | 2^n | 2, 4, 8, 16, 32... | Gravity = 0.2 |
| Prime | nth prime | 2, 3, 5, 7, 11... | Gravity = 0.2 |
| Square | n² | 1, 4, 9, 16, 25... | Gravity = 0.2 |
| Exponential | e^n | 1, 3, 7, 20, 55... | Gravity = 0.2 |
| Triangular | n(n+1)/2 | 1, 3, 6, 10, 15... | Gravity = 0 |
| Linear | n | 1, 2, 3, 4, 5... | Gravity = 0.2 |

## Getting Started

### Prerequisites

- Python 3.x
- Pygame

### Installation
```bash
git clone https://github.com/tbeaudoindavignon/math-balls.git

cd math-balls

pip install pygame numpy

python main.py
```

## Controls

- Press `R` to restart
- Press `ESC` to exit

## Game Rules

First ball to break the three blocks wins.
